# Retro Snake Game in Python

A classic implementation of the arcade game **Snake**, built completely from scratch using Python's built-in `turtle` graphics module. Guide the snake to collect red apples, grow longer, and achieve a new high score!

---

## Features

* **Smooth Mechanics:** Responsive grid-based controls with safety checks to prevent illegal 180-degree self-reversals.
* **Score Tracking:** Real-time score counter and persistent high-score tracker that updates dynamically during your session.
* **Collision Detection:** Triggers an automatic game reset if the snake hits the outer walls or crashes into its own tail.
* **Zero Dependencies:** Runs entirely on Python's standard library—no external pip packages required.

---

## Requirements

* **Python 3.x** installed on your system.

---

1. Save your game script into a file, for example: `snake.py`.
2. Open your terminal or command prompt.
3. Navigate to the folder where you saved the file.
